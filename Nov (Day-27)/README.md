

# Day 27 – Character Frequency + Sort Hybrid

## Overview

Solved character frequency and rearrangement problems using dictionaries, manual merge sort, and greedy techniques without relying on built-in sorting shortcuts.

## Problems Completed

| No. | Problem | Approach |
|---|---|---|
| 1 | Sort Characters By Frequency | Custom Merge Sort |
| 2 | Rearrange Characters to Make Target String | Frequency Analysis |
| 3 | Reorganize String | Greedy Rearrangement |

## Concepts Practised

- Maintaining character frequency dictionaries.
- Applying custom sorting techniques.
- Comparing character frequencies.
- Finding how many target strings can be formed.
- Checking rearrangement feasibility.
- Placing characters to avoid adjacent duplicates.
