# Day 16 – String Prefix Sum Techniques

## Overview

This day focuses on solving string problems using prefix counts, substring analysis, and prefix-based data structures.

## Problems Completed

| No. | Problem | Technique |
|---|---|---|
| 1 | Number of Vowels in Substring Ranges | Prefix Sum |
| 2 | Count Vowel Substrings of a String | Sliding Substring Analysis |
| 3 | Prefix Scores of Strings | Trie |

## Concepts Covered

- Prefix frequency counting.
- Efficient substring range queries.
- Identifying vowel-only substrings.
- Character tracking.
- Trie construction and traversal.
- Prefix score calculation.

## Tools Used

- Python
- GitHub

## Learning Outcome

Strengthened string-processing skills through prefix sums, substring analysis, and Trie-based problem solving.
