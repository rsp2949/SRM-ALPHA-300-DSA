# Day 18 – String Sorting Algorithms

## Overview

This session focuses on solving string-related problems through frequency analysis, greedy techniques, and custom character ordering without using Python's built-in sorting methods.

## Problems Solved

| No. | Problem | Main Concept |
|---|---|---|
| 1 | Sort Characters By Frequency | Frequency Counting and Merge Sort |
| 2 | Reorganize String | Greedy Algorithm |
| 3 | Custom Sort String | Custom Character Ordering |

## Key Concepts

- Character frequency management.
- Manual implementation of sorting logic.
- Greedy character selection.
- Reorganizing characters to avoid adjacent duplicates.
- Maintaining a custom ordering of characters.
- Dictionary-based string processing.

## Restrictions Followed

- No `sorted()`.
- No `.sort()`.
- Implement sorting logic manually.
- No external data structure libraries.

## Technology Used

- Python
- GitHub

## Learning Outcome

Strengthened problem-solving skills involving string manipulation, frequency tracking, greedy selection, and custom ordering techniques.
