

# Day 20 – Minimum Window + Target Cover

## Overview

Solved three string-based problems by applying sliding window, character frequency tracking, and divide-and-conquer techniques.

## Problems Completed

| No. | Problem | Approach |
|---|---|---|
| 1 | Minimum Window Substring | Two Dictionaries, Matched Count |
| 2 | Substrings of Size Three with Distinct Characters | Character Comparison |
| 3 | Longest Nice Substring | Divide and Conquer |

## Concepts Practised

- Tracking required and current character frequencies.
- Managing matched characters in a sliding window.
- Finding valid substrings of fixed length.
- Comparing uppercase and lowercase characters.
- Recursively splitting strings into smaller parts.
